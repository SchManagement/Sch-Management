## Penting
Gambar-gambar ini adalah **art direction reference**, bukan sumber data bisnis.

Gunakan sebagai referensi untuk:
- komposisi
- hierarchy
- dark/light rhythm
- typography
- spacing
- treatment logo SCH
- decorative lighting/geometry
- visual density
- premium corporate technology direction

JANGAN menyalin atau menganggap nyata:
- statistik
- jumlah project/client
- foto founder generatif
- kantor/gedung
- nomor telepon/alamat
- testimonial
- nama project tambahan
- claim bisnis lain yang tidak ada di CMS/data asli

Semua konten produksi tetap harus berasal dari CMS dan data asli SCH Management.

## Target implementasi
Codex harus mempertahankan:
- Laravel / Inertia / Vue architecture
- CMS contracts
- GSAP / ScrollTrigger behavior
- Three.js SCH hero
- branded loader
- SEO
- reCAPTCHA / Lead / SMTP
- conditional analytics consent

Prioritas refinement adalah visual composition, bukan perubahan backend atau motion system.
